编译产物里有两个 bin，`initramfs-kernel.bin` 和 `squashfs-sysupgrade.bin`，官方一句话介绍分别是"集成最小文件系统的 Linux 内核，适用于首次安装或故障恢复"和"用于更新现有 OpenWrt 设备"。这篇讲清楚它们的区别和完整的刷机流程。

## 两种固件的本质区别

| | initramfs-kernel.bin | squashfs-sysupgrade.bin |
|---|---|---|
| 结构 | 内核 + 打包在内核里的完整 rootfs | 内核 + squashfs 只读根 + 可写 overlay |
| 运行位置 | 整体加载进**内存**（K2P 是 128MB）| 写入 **flash**（16MB）|
| 重启后 | 恢复原样，所有改动清零 | 配置、装的包都保留 |
| 类比 | 电脑的 PE / Live USB | 装进硬盘的系统 |
| 用途 | 试机、救援、开发调试 | **日常使用** |

initramfs 能"临时启动"的原理：Breed 支持把镜像直接推进内存并跳转执行，flash 一个字节都不动，断电即回到从前。它是零风险的新固件体检器——每次编出新版本，先在 Breed 里临时启动一次 initramfs，确认无线、网口正常再正式写入 sysupgrade。

至于常见的 factory.bin：内容与 sysupgrade 相同，只是封装格式适配原厂固件的升级校验，用于"从原厂系统首次刷入"。有 Breed 的话刷 sysupgrade 就行。

## Breed 刷机完整流程

**1. 进入 Breed**

- 路由器断电，网线连电脑和 **LAN 口**
- 按住 Reset 不放 → 插电 → 保持约 5 秒，指示灯快速闪烁后松开
- 电脑设静态 IP `192.168.1.2`（Breed 不带 DHCP），掩码 255.255.255.0
- 浏览器访问 `192.168.1.1`

**2. 刷写**

- 「固件更新」→ 只勾选「固件」→ 选择 sysupgrade.bin → 上传 → 提交
- 等 2~3 分钟写入并自动重启
- 电脑改回 DHCP，浏览器进 `192.168.1.1`

注意：**只勾"固件"一项**，不要勾 EEPROM/编程器固件，避免覆盖无线校准数据；Breed 所在分区不要动，它是后悔药，以后刷错随时能回来。

## 刷完后的必要配置

开机 1~2 分钟后进 LuCI（自编固件若选了中文则直接是中文界面）：

1. **安全**：系统 → 管理权，设置 root 密码（SSH 同步生效）
2. **上网**：网络 → 接口 → WAN，家宽拨号选 PPPoE 填账号密码；光猫已拨号则保持 DHCP 客户端
3. **无线**：网络 → 无线，两个射频各设 ESSID 和密码，加密选 WPA2/WPA3 混合，国家代码 CN，5G 建议 36-48 或 149-165 信道开 80MHz
4. **按需**：UPnP（游戏/NAS）、DNS 上游（223.5.5.5 等）、时区 CST-8
5. **保底**：系统 → 备份/升级，先导出一份配置备份；以后升级固件就在这页上传新 sysupgrade 勾选保留配置

## 万一配置搞砸

- LuCI 里：系统 → 备份/升级 → 重置（恢复出厂）
- 完全起不来：按住 Reset 上电恢复，或进 Breed 重刷
- Breed 在，K2P 基本不存在"变砖"这个状态

## 总结

- 刷机刷的是 `squashfs-sysupgrade.bin`，Breed 里直接刷即可
- `initramfs-kernel.bin` 留着当"新固件试运行器"和救援盘
- 配置顺序：密码 → WAN → WiFi → 备份，十分钟搞定

刷机本身是最简单的环节，真正的门槛在编译出一份自己想要的固件——那又是另一篇文章了。
